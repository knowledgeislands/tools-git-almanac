# Guides

Practical instructions for using, developing, and releasing gitlendar. The [Specifications](../specs/index.md) define what the tool does; these guides explain how to work with it.

## Start here

- [Generate an activity calendar](user/activity-calendar.md) — choose a repository, filters, format, and output destination.
- [Local development](developer/local-development.md) — run the checkout directly, link it on PATH, and execute the complete gate.
- [Release and Homebrew](developer/release.md) — verify and publish an immutable release, then complete the tap handoff.
