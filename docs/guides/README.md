# Guides

Practical instructions for using, developing, and releasing Git Almanac. [Specifications](../specs/index.md) define what the tool does; Guides explain how to work with it.

## Start here

- [Use Git Almanac](user/git-almanac.md) — select history, inspect identities, export views, configure defaults, and maintain reports.
- [Local development](developer/local-development.md) — run the checkout directly, link it on `PATH`, and execute the complete gate.
- [Release and Homebrew](developer/release.md) — verify and publish an immutable release, then complete the receiver-owned tap handoff.
