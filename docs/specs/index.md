# Specifications

This corpus defines the as-built behavior of Git Almanac. Requirements state what the system does; Guides explain how to use it, and roadmap items record when changes were delivered.

## How to read a requirement

Each requirement uses an append-only `<PREFIX>-<NNN>` identifier, one uppercase normative statement, and a concrete verification hook.
