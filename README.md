# gitlendar

Turn one local Git repository's activity into a trustworthy annual calendar.

The initial delivery is tracked in [GITLENDAR-CLI-001](docs/roadmap/GITLENDAR-CLI-001-initial-calendar.md).

## Development bootstrap

The repository is being prepared through the Knowledge Islands roadmap lifecycle. Run the direct development entry point with ./bin/gitlendar --help.
